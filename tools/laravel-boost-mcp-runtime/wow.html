Laravel Boost MCP

Runtime w G:\gravity\tools\laravel-boost-mcp-runtime (jak GitHub MCP). Uruchamia php artisan boost:mcp w katalogu projektu G:\gravity - dokumentacja Laravel, search-docs, narzędzia Boost pod Cursor.

Checklist

  1. Zainstaluj PHP 8.5+ albo ustaw GRAVITY_PHP / plik php.path.
  2. composer install w G:\gravity (pakiet laravel/boost).
  3. Uruchom setup-laravel-boost-wow.ps1 lub install-laravel-boost-mcp.ps1.
  4. W Cursorze: przeładuj serwer MCP laravel-boost.
